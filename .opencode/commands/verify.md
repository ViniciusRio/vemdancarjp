---
description: Executa as verificações principais do projeto (lint, type-check, testes).
---

Execute, nesta ordem:

1. `npm run lint`
2. `npm run type-check`
3. `npm run test:unit`

Relate cada resultado separadamente (comando + status de saída + trecho relevante em caso de falha). Não corrija falhas automaticamente sem antes explicar o que será alterado. Se uma falha for preexistente (não causada pela mudança em pauta), marque-a como tal.
